# ---- Evaluation harness -----------------------------------------------------
# !! MTEB v2 IS REQUIRED - NOT v1. !!
# The whole pipeline is written against the v2 API surface:
#   - `mteb.evaluate(model, tasks=...)`      (v1 used `MTEB(tasks).run(model)`)
#   - `AbsEncoder` / `EncoderProtocol`       (v2 `encode()` takes a DataLoader
#                                             of batches, NOT a `list[str]`)
#   - `SearchProtocol`                       (v2-only: custom `index()`/`search()`
#                                             so our real hybrid pipeline - not a
#                                             bare encoder - produces the scores)
# A v1 install will fail at import, not at runtime, so pin a >=2 release.
